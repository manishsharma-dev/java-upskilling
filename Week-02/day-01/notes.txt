ABSTRACT CLASS
Common base abstraction.
Can hold instance state, constructors, implemented methods
and abstract methods.

INTERFACE
Defines a contract/capability a class can implement.

extends → class inheritance
implements → interface implementation

A class extends one class but can implement multiple interfaces.
